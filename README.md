# COFI: знакомства по интересам

Одна лента, которая подбирает людей рядом по общим интересам. При регистрации человек проходит короткий опрос
(что ищет, хобби, музыка, кино, выходные, ценности) с выбором нескольких вариантов. Свайпы как в Tinder, пары,
мессенджер с фото, видео, голосовыми, кружочками, стикерами и звонками. Есть админ-панель.

Бэкенд — FastAPI + SQLite (SQLAlchemy), фронтенд — чистый JS без сборки, realtime — WebSocket, звонки — WebRTC.

## Запуск через командную строку

Нужен **Python 3.10–3.13** ([python.org](https://www.python.org/downloads/)). На Windows при установке отметьте **Add python.exe to PATH**.
Проверка: `python --version` (на macOS/Linux `python3 --version`).

Все команды выполняются **из папки проекта**, в которой лежат `run.py` и `requirements.txt`.
Если скачали zip, это папка `cofi` внутри архива, если клонировали с GitHub, это `spark-dating`.

### Windows: PowerShell (терминал PyCharm, VS Code)

```powershell
cd C:\путь\к\cofi                        # папка, где лежит run.py
python -m venv venv                       # один раз: виртуальное окружение
venv\Scripts\Activate.ps1                 # в начале строки появится (venv)
pip install -r requirements.txt           # один раз: зависимости
python run.py                             # сервер на http://localhost:8000
```

Если `Activate.ps1` пишет «выполнение сценариев отключено», один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите активацию.

### Windows: командная строка (cmd)

```bat
cd /d C:\путь\к\cofi
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
python run.py
```

Или просто двойной клик по `Запуск.bat`: он сделает всё то же самое и откроет браузер.

### macOS и Linux

```bash
cd ~/путь/к/cofi
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```

Или одной командой: `./start.sh` (если не запускается, сначала `chmod +x start.sh`).

### Открыть приложение

- Приложение: http://localhost:8000
- Админ-панель: http://localhost:8000/admin
- Остановить сервер: `Ctrl+C` в терминале.

При следующих запусках достаточно двух команд: активировать окружение (`venv\Scripts\Activate.ps1`,
`venv\Scripts\activate.bat` или `source venv/bin/activate`) и выполнить `python run.py`.

### Первый вход

1. Нажмите **«Демо без регистрации»**, чтобы сразу посмотреть ленту с ботами (взрослую или для 12–17 лет).
2. Или зарегистрируйтесь по почте. Почта для локального запуска не нужна: 6-значный код показывается
   прямо на экране и печатается в терминале.
3. Чтобы стать админом, остановите сервер и выполните `python -m app.cli make-admin ваша@почта.ру`,
   затем снова `python run.py`.
4. Проверка лица включает камеру браузера. Без камеры её можно отключить, см. `FACE_MODE=dev` ниже.

Модели для проверки лица (~38 МБ) уже лежат в папке `models` в архиве. Если папки нет (клон с GitHub),
скачайте их: `python -m app.cli download-models`.

### Полезные команды

Выполнять в той же папке с активированным окружением.

| Что | Команда |
|---|---|
| Выдать права админа | `python -m app.cli make-admin you@mail.ru` |
| 12 тестовых анкет рядом с Москвой (пароль `Demo12345`) | `python -m app.cli seed --lat 55.75 --lon 37.62` |
| Другой порт | PowerShell: `$env:PORT=8080; python run.py` · cmd: `set PORT=8080`, затем `python run.py` · macOS/Linux: `PORT=8080 python run.py` |
| Без проверки лица (нет камеры) | PowerShell: `$env:FACE_MODE="dev"; python run.py` · cmd: `set FACE_MODE=dev`, затем `python run.py` · macOS/Linux: `FACE_MODE=dev python run.py` |
| Боты в демо отвечают сразу | так же, переменная `DEMO_REPLY_DELAY=0` |
| Начать с чистой базы | остановить сервер и удалить папку `data` |
| Тесты (в репозитории на GitHub, в архив не входят) | `pip install -r requirements-dev.txt` и затем `pytest` |

### Частые ошибки

| Ошибка | Что сделать |
|---|---|
| `python` не найден / открывается Microsoft Store | Установите Python с python.org с галочкой «Add to PATH» или используйте `py` вместо `python`. |
| `Не удается найти путь` при `cd` | Вы не в той папке. `dir` (Windows) или `ls` покажут содержимое: нужна папка, где виден `run.py`. |
| `No module named fastapi` | Не активировано окружение или не выполнен `pip install -r requirements.txt`. |
| `address already in use` / порт 8000 занят | Сервер уже запущен в другом окне, закройте его или запустите на другом порту. |
| Браузер пишет `ERR_ADDRESS_INVALID` на `0.0.0.0:8000` | В терминале uvicorn показывает служебный адрес `0.0.0.0`. Открывайте http://localhost:8000. |
| Камера или геопозиция не работают | Они работают только на `localhost` или по HTTPS. Откройте именно http://localhost:8000, а не IP-адрес. |
| Код из письма не приходит | Пока почта не подключена, это нормально: код показан на экране. Подключение почты описано в разделе «Почта Outlook». Проверить отправку: `python -m app.cli test-email ваш@ящик`. |

### Настройки (`.env`)

В архиве уже лежит `.env` для локального запуска: почта Outlook, админ, режим разработки. Осталось вписать
`OUTLOOK_CLIENT_ID` и `TELEGRAM_BOT_TOKEN` (разделы ниже). Полный список настроек с пояснениями: `.env.example`.
Для настоящего сайта поменяйте `DEV_MODE=0`, `COOKIE_SECURE=1`, `BASE_URL` и `SECRET_KEY`.

## Что умеет

| Вход через Telegram | Кнопка «Войти через Telegram» открывает бота COFI, человек нажимает «Войти» (бот показывает, с какого браузера вход), и страница входит сама. Работает и на localhost, домен в BotFather не нужен. Почта и пароль не нужны, но фото всё равно проходит проверку. |
| Фото | Загрузить из галереи или «Сделать фото сейчас» фронтальной камерой прямо на странице (превью, «Переснять», «Использовать»). |
| Проверка фото на фейк | После загрузки фото открывается сканер лица: «смотрите прямо → поверните влево → вправо». Сервер (OpenCV YuNet + SFace) сверяет каждый кадр с фото и проверяет, что голова поворачивалась, поэтому чужое фото, поднесённое к камере, проверку не пройдёт. Пока фото не подтверждено, анкету никто не видит. Новое фото — новая проверка. |
| Опрос | 6 вопросов, по одному на экран, можно выбрать несколько вариантов: что ищете (9), хобби (44), музыка (28), кино (26), выходные (30), ценности (26). Минимум 3 интереса. Всё меняется в «Профиле». |
| Пол и ориентация | В «Знакомствах»: парень, девушка, трансгендерный парень, трансгендерная девушка и необязательная ориентация (гетеросексуал, бисексуал, пансексуал, асексуал). В «Дружбе» только парень или девушка, ориентацию не спрашиваем. Переключатель «Показывать в анкете» на шаге «Знакомимся» и в профиле. Для «кого ищу» трансгендерный парень считается парнем, трансгендерная девушка — девушкой. |
| Подбор | Одна лента. Сначала люди с наибольшим совпадением интересов, при равенстве ближайшие. На карточке процент совпадения, число общих увлечений, расстояние и общие интересы. Учитывается, кого ищут оба. Карточка в стиле Threads: круглое фото, описание и общие интересы бусинами на нитке. Свайп по нитке вниз: нравится, вверх: дальше (или кнопки ♥ и ✕, закреплены над нижним меню). Остальной экран, включая фото, свободно листается и на анкету не отвечает. Нажатие на фото открывает подробную анкету: до 7 фото, описание, все интересы, общие отмечены. Писать можно только после взаимной симпатии. |
| Пара | Экран «Взаимно» с общими интересами, уведомление в реальном времени и письмо на почту, после этого открывается чат. |
| Мессенджер | Текст, фото, видео, голосовые, кружочки (до 60 с), стикеры, «печатает…», прочитано ✓✓, аудио- и видеозвонки, удаление пары. Медиа доступны только участникам чата. |
| Ленты | «Знакомства» с 18 лет (свайпы, подбор по интересам), «Дружба» до 18 лет (только дружеские цели, можно выбрать, кого ищешь: парня, девушку или всех) и «Питомцы». Подростки и взрослые полностью изолированы: не видят анкеты друг друга, не могут лайкнуть или написать, а если кто-то сменил группу, старые чаты закрываются. |
| Проверка возраста | Дата рождения обязательна, младше 12 лет регистрация закрыта. Возраст считается от даты каждый день (в 18 лет человек сам переходит во взрослую ленту). Поменять дату самому нельзя, только через поддержку: админ правит её в панели и отмечает «проверено по документу». Для юридически значимой проверки подключите проверку документа (Госуслуги или KYC-сервис), место под это уже есть (`age_verified`). |
| Возраст и соглашение | На шаге «Знакомимся» плашка с двумя обязательными галочками: «Подтверждаю, что мне исполнилось 18 лет» (для 12–17 лет текст меняется на согласие родителей) и «Принимаю Пользовательское соглашение». Без них дальше не пройти. Согласие и его редакция сохраняются у пользователя. Соглашение открывается поверх экрана, введённые данные не теряются, отдельная страница `/#/terms`, ссылка в профиле. |

| Уведомления | Всплывающие сообщения сверху, смахиваются вверх. |
| Вернуть | Кнопка «Вернуть» в ленте людей возвращает случайно пролистанную анкету или отменяет лайк (до 20 шагов назад). Если лайк уже дал пару и в чате есть сообщения, отменить нельзя: пару удаляют в чате. |
| Питомцы | Три категории в таком порядке: «Ищут дом», «Передержка», «Помощь и сборы» (админ переключает «Сбор открыт / закрыт», в сборе есть цель, например «Стерилизация бездомных животных», 20 000 ₽). По нажатию на объявление открывается подробная карточка. |

## Пользователи младше 14 лет

По 152-ФЗ персональные данные детей до 14 лет обрабатываются только с согласия родителей. Перед запуском добавьте
согласие законного представителя для регистраций 12–13 лет (например, подтверждение по почте родителя) и пропишите
это в пользовательском соглашении.

## Telegram: вход и заявки

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя и username бота, скопируйте токен.
2. В `.env`: `TELEGRAM_BOT_TOKEN=123456:ABC…`. Больше ничего не нужно: username бота сервер узнаёт сам, домен указывать не надо.
3. Перезапустите `python run.py`. В терминале появится «Telegram-бот @… запущен», на экране входа кнопка «Войти через Telegram» заработает.
4. Как это выглядит: кнопка → «Открыть Telegram» → в боте «Запустить» → «✅ Войти» → браузер входит сам.
   Если бот не отвечает: серверу нужен доступ к api.telegram.org, и этот же токен не должен работать в другой программе или с вебхуком.
5. Заявки «Помочь» по питомцам: добавьте бота в группу волонтёров, узнайте её id (например, через @getidsbot) и пропишите
   `TELEGRAM_REQUESTS_CHAT_ID=-100…`. Кроме того, заявки приходят лично автору объявления, если он входил через Telegram и запустил бота.

## Уведомления на телефон и звонки тем, кто не в сети

Уведомления приходят через вашего Telegram-бота: Telegram показывает их вверху экрана со звуком, даже когда COFI закрыт.
- **Сообщения** (не чаще раза в минуту на чат) и **взаимные симпатии** — с кнопкой «Открыть чат».
- **Звонки** человеку не в сети: «📞 Звонок от …» с кнопками «✅ Ответить» и «❌ Отклонить». «Ответить» открывает COFI
  внутри Telegram и сразу соединяет. Звонящий видит «Звонок отправлен в Telegram, ждём ответа…», ждём до 75 секунд.
  Не взяли трубку — сообщение меняется на «Пропущенный звонок».
- **Пропущенный вызов:** если звонок не взяли, бот присылает отдельное сообщение «📵 Пропущенный вызов от …» с кнопкой «Перезвонить».
- Если человек сейчас в приложении и оно на экране, звонок показывается плашкой вверху с кнопками «Ответить» и «Отклонить».
  Свёрнутое мини-приложение или вкладка в фоне считаются «не в приложении»: уведомления приходят в Telegram.
- Не пришло уведомление — смотрите терминал сервера: там написано, отправлено ли оно и почему нет
  (Telegram не подключён, уведомления выключены, человек не нажал «Запустить» в боте).

Что нужно:
1. `TELEGRAM_BOT_TOKEN` в `.env` (раздел «Telegram»).
2. Публичный `https://` адрес в `BASE_URL` (свой домен или туннель cloudflared). Без него уведомления приходят,
   но без кнопок, открывающих COFI.
3. Кто вошёл через Telegram, получает уведомления сразу. Кто зарегистрировался по почте, нажимает в профиле
   «Подключить уведомления в Telegram». Выключить их можно там же.
4. В @BotFather → бот → Bot Settings → Menu Button укажите тот же `https://` адрес: COFI откроется кнопкой «Меню»,
   и вход произойдёт сам, без пароля.

Адрес туннеля cloudflared меняется при каждом запуске: после смены обновите `BASE_URL` и Menu Button,
иначе кнопки в старых уведомлениях перестанут открывать COFI.

## Администраторы

Администратору не нужна анкета: при первом входе COFI спрашивает только имя, дальше рядом с ним значок «Администрация».
- В `.env`: `ADMIN_EMAILS=почта1,почта2` — эти почты становятся админами сами при входе.
- В админ-панели, вкладка «Анкеты» → «Добавить администратора»: имя и почта с паролем, или @username того, кто уже входил через Telegram.
- Из терминала: `python -m app.cli create-admin --name "Оля" --email olya@mail.ru --password Secret123`
  или `python -m app.cli make-admin @username` (Telegram) / `python -m app.cli make-admin почта@mail.ru`.

Обращения в поддержку, жалобы, предложения и заявки на рекламу приходят в админ-панель (вкладка «Обращения») и в Telegram:
в группу из `TELEGRAM_ADMIN_CHAT_ID` (id группы, бот должен в ней состоять) или, если он пуст, каждому админу с привязанным Telegram.

## Почта Outlook: коды подтверждения с вашего ящика

Microsoft больше не принимает отправку писем с личного Outlook.com / Hotmail по паролю (даже по паролю приложения),
поэтому COFI входит в ящик через Microsoft (OAuth2). Настройка один раз, около 5 минут:

1. Откройте [entra.microsoft.com](https://entra.microsoft.com) или [portal.azure.com](https://portal.azure.com) под своим аккаунтом Microsoft,
   раздел **Регистрация приложений** (App registrations) → **Новая регистрация**.
   Имя: `COFI`. Типы учётных записей: **Только личные учётные записи Майкрософт** (Personal Microsoft accounts only).
   URI перенаправления не нужен. Нажмите «Зарегистрировать».
2. Скопируйте **Идентификатор приложения (клиента)** (Application (client) ID) и вставьте в `.env`: `OUTLOOK_CLIENT_ID=…`.
3. Там же **Проверка подлинности** (Authentication) → **Разрешить потоки общедоступных клиентов** (Allow public client flows) → **Да** → Сохранить.
4. Проверьте, что в `.env` стоят строки для Outlook (уже заполнены в `.env` из архива):
   ```
   SMTP_AUTH=outlook
   SMTP_HOST=smtp-mail.outlook.com
   SMTP_PORT=587
   SMTP_SSL=0
   SMTP_USER=ваш@outlook.com
   SMTP_FROM=COFI <ваш@outlook.com>
   ```
5. В терминале проекта: `python -m app.cli outlook-login`. Команда покажет ссылку и код: откройте ссылку, введите код,
   войдите в тот же ящик и разрешите отправку писем. Токен сохранится в `data/outlook_token.json`.
6. Проверка: `python -m app.cli test-email ваш@outlook.com`, затем `python run.py`.

Пока почта не подключена, при `DEV_MODE=1` код по-прежнему показывается на экране и в терминале, так что регистрация не ломается.
Если Microsoft не даёт зарегистрировать приложение, проще взять почту Яндекса: `SMTP_AUTH=password`, `SMTP_HOST=smtp.yandex.ru`,
`SMTP_PORT=465`, `SMTP_SSL=1`, `SMTP_USER`, `SMTP_FROM` и `SMTP_PASSWORD` (пароль приложения из настроек Яндекс ID).

## Звонки: TURN для мобильного интернета

Звонок проходит напрямую между телефонами. В одном Wi-Fi или дома это обычно работает сразу. Если у кого-то мобильный
интернет (4G/5G), оператор чаще всего не пускает прямое соединение, и звонок висит на «Соединяем…», а через 20 секунд
COFI пишет «Не получилось соединиться». Нужен TURN-сервер: он пересылает звук и видео.

Бесплатный вариант для проверки — Metered (бесплатно 20 ГБ в месяц, хватит на десятки часов звонков):
1. Зарегистрируйтесь на [metered.ca](https://www.metered.ca/stun-turn) и создайте приложение TURN.
2. В кабинете откройте учётные данные TURN (Credentials): там адреса `turn:…`, логин (username) и пароль (credential).
3. Впишите в `.env`:
   ```
   TURN_URLS=turn:global.relay.metered.ca:80,turn:global.relay.metered.ca:80?transport=tcp,turn:global.relay.metered.ca:443,turns:global.relay.metered.ca:443?transport=tcp
   TURN_USERNAME=логин_из_кабинета
   TURN_CREDENTIAL=пароль_из_кабинета
   ```
   Адреса берите те, что показывает ваш кабинет, если они отличаются.
4. Перезапустите `python run.py` и обновите страницу у обоих собеседников.

Для постоянной работы можно поставить свой TURN (coturn) на сервер с сайтом.

## Пользовательское соглашение

Текст лежит в `static/js/terms.js`. Перед запуском:
1. Впишите реквизиты в `OPERATOR` в начале файла: ФИО или название ИП/ООО, ИНН, ОГРН, адрес, почту для обращений.
2. Дайте текст проверить юристу. Это шаблон: полностью снять ответственность с сервиса закон не позволяет
   (ст. 401 ГК РФ, закон «О защите прав потребителей»), поэтому ограничения действуют «в пределах, допустимых законом».
3. Подайте уведомление в Роскомнадзор об обработке персональных данных (ст. 22 152-ФЗ): сервис обрабатывает
   фото лица для сверки, это может считаться биометрией.
4. Изменили текст по существу — поднимите `TERMS_VERSION` в `app/legal.py`: при следующем входе все снова примут соглашение.

## Безопасность

- Код подтверждения на экране (`DEV_MODE=1`) показывается, только когда сайт открыт на этом же компьютере (localhost).
  Через туннель cloudflared или из интернета код приходит только на почту, поэтому для регистрации по почте нужен рабочий SMTP.
- Проверка на робота при входе, регистрации и сбросе пароля: своя картинка с цифрами (одноразовая, 5 минут, ответ хранится
  только как хэш). Можно включить Cloudflare Turnstile: `CAPTCHA=turnstile`, `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET`
  (бесплатно на dash.cloudflare.com → Turnstile). Вход через Telegram проверку не требует: его защищает сам Telegram.
- Ограничение попыток: вход (10 неверных паролей к одной почте за 15 минут, 30 попыток с адреса за 10 минут), коды, сброс пароля,
  регистрация, демо, вход через Telegram, обращения в поддержку и заявки «Помочь».
- Расстояние до людей показывается целыми километрами по координатам, привязанным к сетке ~2 км. Так нельзя вычислить,
  где живёт человек, подделав свою геопозицию в нескольких точках.
- Cookie входа: HttpOnly, SameSite=Lax, Secure при https. После сброса пароля все старые входы завершаются.
- Защитные заголовки (nosniff, frame-ancestors, Referrer-Policy, HSTS по https), ответы API не кэшируются.
- WebSocket принимает подключения только со страниц самого COFI.
- Фото пересохраняются без метаданных (в том числе без GPS). Файлы из чатов (фото, видео, голосовые, кружочки) открывают только двое участников чата и администраторы, остальным — отказ. Кадр проверки лица видят только владелец и админ.

## Перед продакшеном

- Задайте `SECRET_KEY`, `DEV_MODE=0`, `COOKIE_SECURE=1`, настройте SMTP и HTTPS (nginx + certbot).
- Для звонков через мобильные сети настройте TURN (раздел «Звонки»).
- Админ видит переписки, Пропишите это в пользовательском соглашении и политике конфиденциальности (152-ФЗ / GDPR) и укажите возрастную маркировку 18+.
- При большой нагрузке SQLite стоит заменить на PostgreSQL (`DATABASE_URL`), а файлы перенести в S3.
