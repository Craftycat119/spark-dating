# COFI: знакомства по интересам

Одна лента, которая подбирает людей рядом по общим интересам. При регистрации человек проходит короткий опрос
(что ищет, хобби, музыка, кино, выходные, ценности) с выбором нескольких вариантов. Свайпы как в Tinder, пары,
мессенджер с фото, видео, голосовыми, кружочками, стикерами и звонками. Есть админ-панель.

Бэкенд — FastAPI + SQLite (SQLAlchemy), фронтенд — чистый JS без сборки, realtime — WebSocket, звонки — WebRTC.

## Запуск через командную строку

Нужен **Python 3.10–3.13** ([python.org](https://www.python.org/downloads/)). На Windows при установке отметьте **Add python.exe to PATH**.
Проверка: `python --version` (на macOS/Linux `python3 --version`).

Все команды выполняются **из папки проекта**, в которой лежат `run.py` и `requirements.txt`.
Если скачали zip, это папка `cofi` внутри архива, если клонировали с GitHub, это `spark-dating`.

### Windows: PowerShell (терминал PyCharm, VS Code)

```powershell
cd C:\путь\к\cofi                        # папка, где лежит run.py
python -m venv venv                       # один раз: виртуальное окружение
venv\Scripts\Activate.ps1                 # в начале строки появится (venv)
pip install -r requirements.txt           # один раз: зависимости
python run.py                             # сервер на http://localhost:8000
```

Если `Activate.ps1` пишет «выполнение сценариев отключено», один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите активацию.

### Windows: командная строка (cmd)

```bat
cd /d C:\путь\к\cofi
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
python run.py
```

Или просто двойной клик по `Запуск.bat`: он сделает всё то же самое и откроет браузер.

### macOS и Linux

```bash
cd ~/путь/к/cofi
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```

Или одной командой: `./start.sh` (если не запускается, сначала `chmod +x start.sh`).

### Открыть приложение

- Приложение: http://localhost:8000
- Админ-панель: http://localhost:8000/admin
- Остановить сервер: `Ctrl+C` в терминале.

При следующих запусках достаточно двух команд: активировать окружение (`venv\Scripts\Activate.ps1`,
`venv\Scripts\activate.bat` или `source venv/bin/activate`) и выполнить `python run.py`.

### Первый вход

1. Нажмите **«Демо без регистрации»**, чтобы сразу посмотреть ленту с ботами (взрослую или для 12–17 лет).
2. Или зарегистрируйтесь по почте. Почта для локального запуска не нужна: 6-значный код показывается
   прямо на экране и печатается в терминале.
3. Чтобы стать админом, остановите сервер и выполните `python -m app.cli make-admin ваша@почта.ру`,
   затем снова `python run.py`.
4. Проверка лица включает камеру браузера. Без камеры её можно отключить, см. `FACE_MODE=dev` ниже.

Модели для проверки лица (~38 МБ) уже лежат в папке `models` в архиве. Если папки нет (клон с GitHub),
скачайте их: `python -m app.cli download-models`.

### Полезные команды

Выполнять в той же папке с активированным окружением.

| Что | Команда |
|---|---|
| Выдать права админа | `python -m app.cli make-admin you@mail.ru` |
| 12 тестовых анкет рядом с Москвой (пароль `Demo12345`) | `python -m app.cli seed --lat 55.75 --lon 37.62` |
| Другой порт | PowerShell: `$env:PORT=8080; python run.py` · cmd: `set PORT=8080`, затем `python run.py` · macOS/Linux: `PORT=8080 python run.py` |
| Без проверки лица (нет камеры) | PowerShell: `$env:FACE_MODE="dev"; python run.py` · cmd: `set FACE_MODE=dev`, затем `python run.py` · macOS/Linux: `FACE_MODE=dev python run.py` |
| Боты в демо отвечают сразу | так же, переменная `DEMO_REPLY_DELAY=0` |
| Начать с чистой базы | остановить сервер и удалить папку `data` |
| Тесты | `pip install -r requirements-dev.txt` и затем `pytest` |
| Демо в один HTML-файл | открыть `cofi-demo.html` из архива двойным кликом, сервер не нужен |

### Частые ошибки

| Ошибка | Что сделать |
|---|---|
| `python` не найден / открывается Microsoft Store | Установите Python с python.org с галочкой «Add to PATH» или используйте `py` вместо `python`. |
| `Не удается найти путь` при `cd` | Вы не в той папке. `dir` (Windows) или `ls` покажут содержимое: нужна папка, где виден `run.py`. |
| `No module named fastapi` | Не активировано окружение или не выполнен `pip install -r requirements.txt`. |
| `address already in use` / порт 8000 занят | Сервер уже запущен в другом окне, закройте его или запустите на другом порту. |
| Камера или геопозиция не работают | Они работают только на `localhost` или по HTTPS. Откройте именно http://localhost:8000, а не IP-адрес. |
| Код из письма не приходит | Для локального запуска это нормально: код показан на экране. Не копируйте `.env.example` в `.env`, пока не настроили SMTP: в нём `DEV_MODE=0`, и код перестанет показываться. |

### Настройки (`.env`)

Для локального запуска файл не нужен. Для настоящего сайта скопируйте `.env.example` в `.env`
(`copy .env.example .env` на Windows, `cp .env.example .env` на macOS/Linux) и заполните: почту (SMTP), `SECRET_KEY`,
`ADMIN_EMAILS`, бота Telegram. Подробнее в разделах ниже.

## Что умеет

| Раздел | Как устроено |
|---|---|
| Регистрация по почте | Пароль: от 8 символов, заглавная буква, цифра. На почту приходит 6-значный код (15 минут, 5 попыток, повторная отправка через 60 с). Есть сброс пароля. |
| Вход через Telegram | Telegram Login Widget, подпись проверяется на сервере. Почта и пароль не нужны, но фото всё равно проходит проверку. |
| Проверка фото на фейк | После загрузки фото открывается сканер лица: «смотрите прямо → поверните влево → вправо». Сервер (OpenCV YuNet + SFace) сверяет каждый кадр с фото и проверяет, что голова поворачивалась, поэтому чужое фото, поднесённое к камере, проверку не пройдёт. Пока фото не подтверждено, анкету никто не видит. Новое фото — новая проверка. |
| Опрос | 6 вопросов, по одному на экран, можно выбрать несколько вариантов: что ищете, хобби, музыка, кино, выходные, ценности. Минимум 3 интереса. Плюс пол и кого ищете. Всё меняется в «Профиле». |
| Подбор | Одна лента. Сначала люди с наибольшим совпадением интересов, при равенстве ближайшие. На карточке процент совпадения, число общих увлечений, расстояние и общие интересы. Учитывается, кого ищут оба. Карточка в стиле Threads: круглое фото, описание и общие интересы бусинами на нитке. Свайп по нитке вниз: нравится, вверх: дальше (или кнопки ♥ и ✕, закреплены над нижним меню). Остальной экран, включая фото, свободно листается и на анкету не отвечает. Нажатие на фото открывает подробную анкету: до 7 фото, описание, все интересы, общие отмечены. Писать можно только после взаимной симпатии. |
| Пара | Экран «Взаимно» с общими интересами, уведомление в реальном времени и письмо на почту, после этого открывается чат. |
| Мессенджер | Текст, фото, видео, голосовые, кружочки (до 60 с), стикеры, «печатает…», прочитано ✓✓, аудио- и видеозвонки, удаление пары. Медиа доступны только участникам чата. |
| Ленты | «Знакомства» с 18 лет (свайпы, подбор по интересам), «Дружба» до 18 лет (только дружеские цели, можно выбрать, кого ищешь: парня, девушку или всех) и «Питомцы». Подростки и взрослые полностью изолированы: не видят анкеты друг друга, не могут лайкнуть или написать, а если кто-то сменил группу, старые чаты закрываются. |
| Проверка возраста | Дата рождения обязательна, младше 12 лет регистрация закрыта. Возраст считается от даты каждый день (в 18 лет человек сам переходит во взрослую ленту). Поменять дату самому нельзя, только через поддержку: админ правит её в панели и отмечает «проверено по документу». Для юридически значимой проверки подключите проверку документа (Госуслуги или KYC-сервис), место под это уже есть (`age_verified`). |
| Назад при регистрации | На экране кода из письма, сброса пароля и на каждом шаге анкеты есть кнопка «Назад». С первого шага «Сменить способ входа» возвращает к выбору: почта или Telegram. Начатая регистрация сохраняется и продолжится при следующем входе. |
| Уведомления | Всплывающие сообщения сверху, смахиваются вверх. |
| Вернуть | Кнопка «Вернуть» в ленте людей возвращает случайно пролистанную анкету или отменяет лайк (до 20 шагов назад). Если лайк уже дал пару и в чате есть сообщения, отменить нельзя: пару удаляют в чате. |
| Питомцы | Три категории: «Помощь и сборы» (админ переключает «Сбор открыт / закрыт», в сборе есть цель, например «Стерилизация бездомных животных», 20 000 ₽), «Передержка», «Ищет хозяина». Листание вперёд и назад (стрелки, свайп влево и вправо, клавиши ← →). Вместо лайков одна кнопка «Помочь»: ссылка на Telegram автора или группы и заявка, которую бот отправляет в Telegram. Объявления добавляет только администрация (вкладка «Питомцы» в админ-панели: форма с фото, переключатель сбора, снятие с публикации). Отправлять заявки можно с 18 лет. По нажатию на объявление открывается подробная карточка. |
| Поддержка | Раздел в профиле: «Нужна помощь», «Пожаловаться», «Предложить идею», плюс «Пожаловаться на анкету» в любой анкете. Бот сначала здоровается и спрашивает, что случилось, а после первого сообщения пользователя подтверждает, что обращение принято. Оператор отвечает из админ-панели (вкладка «Обращения») в реальном времени. |
| Реклама | Чат-помощник для рекламодателей (`/#/ads`, ссылка на экране входа и в профиле). Работает без аккаунта. Отвечает про форматы, стоимость и аудиторию (берёт реальную статистику из базы), передаёт диалог менеджеру. |
| Язык | Русский и английский: переключатель в профиле и кнопка EN/RU на экране входа. Сообщения и описания пользователей не переводятся. |
| Демо | Кнопка «Демо без регистрации» на экране входа и в инструкции. Сначала выбор: «Мне 18 или больше» или «Мне 12–17». Создаёт временный аккаунт (живёт сутки) и показывает 10 взрослых анкет-ботов (или 6 подростковых в ленте «Дружба»): трое идеально подходят, трое совсем нет, остальные посередине. У каждого 4 фото и подробное описание. Трое ботов уже лайкнули гостя, так что пары случаются сразу, а в чате боты отвечают. Боты и гости не видны реальным пользователям. Фото ботов грузятся с randomuser.me и picsum.photos, без интернета показывается фирменная заглушка. |
| Инструкция `#/guide` | Одна страница: сверху анимированный ролик на настоящих компонентах ленты (свайп вниз, свайп вверх, анкета, взаимная симпатия), ниже основные функции. |
| Тема | Тёмная, светлая или как в системе: переключатель в профиле и на экране входа. |
| Админка `/admin` | Статистика и популярные интересы, фильтр анкет по интересу, поиск по анкетам, карточка пользователя: когда и откуда зарегистрировался (IP, координаты на карте, устройство), фото анкеты рядом с кадром сканера, история входов. Блокировка, сброс проверки, удаление анкеты, чтение переписок, e-mail рассылка об обновлениях. |

## Структура

```
cofi/ (или spark-dating/)
├── app/
│   ├── main.py            FastAPI, раздача файлов с проверкой доступа
│   ├── models.py          таблицы БД
│   ├── interests.py       вопросы опроса и формула совпадения
│   ├── demo.py            демо-режим: гость, 10 ботов, их ответы
│   ├── face_verify.py     сверка лица и проверка «живости»
│   ├── emailer.py         письма (коды, метчи, рассылки)
│   ├── telegram_auth.py   проверка подписи Telegram
│   ├── realtime.py        WebSocket-соединения
│   ├── cli.py             make-admin, seed, download-models
│   └── routers/           auth, profile, feed (подбор), chat (+ сигналинг звонков), admin
├── static/                index.html, admin.html, css/, js/, vendor/ (иконки Phosphor)
├── tools/standalone-demo/ сборка демо в один HTML-файл без сервера (node build.mjs)
└── tests/
```

## Пользователи младше 14 лет

По 152-ФЗ персональные данные детей до 14 лет обрабатываются только с согласия родителей. Перед запуском добавьте
согласие законного представителя для регистраций 12–13 лет (например, подтверждение по почте родителя) и пропишите
это в пользовательском соглашении.

## Telegram: вход и заявки

1. Создайте бота у [@BotFather](https://t.me/BotFather) (`/newbot`), получите токен.
2. Там же `/setdomain` → укажите домен сайта (без него виджет входа не покажется).
3. В `.env`: `TELEGRAM_BOT_TOKEN=…` и `TELEGRAM_BOT_USERNAME=имя_бота`. На экране входа появится кнопка Telegram. Почта и пароль не нужны, дату рождения и фото человек подтверждает при первом входе.
4. Заявки «Помочь» по животным: добавьте бота в группу волонтёров, узнайте её id (например, через @getidsbot) и пропишите `TELEGRAM_REQUESTS_CHAT_ID=-100…`. Кроме того, заявки приходят лично автору объявления, если он входил через Telegram и запустил бота.

## Перед продакшеном

- Задайте `SECRET_KEY`, `DEV_MODE=0`, `COOKIE_SECURE=1`, настройте SMTP и HTTPS (nginx + certbot).
- Для звонков через мобильные сети поднимите TURN-сервер (coturn) и пропишите его в `ICE_SERVERS`.
- Админ видит переписки, Пропишите это в пользовательском соглашении и политике конфиденциальности (152-ФЗ / GDPR) и укажите возрастную маркировку 18+.
- При большой нагрузке SQLite стоит заменить на PostgreSQL (`DATABASE_URL`), а файлы перенести в S3.
