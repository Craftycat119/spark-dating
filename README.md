# Spark — приложение знакомств на Python

Один профиль и три ленты: **Знакомства**, **18+** и **Дружба / компания**. Свайпы как в Tinder, метчи,
мессенджер с фото, видео, голосовыми, кружочками, стикерами и звонками (голос и видео). Есть админ-панель.

Бэкенд — FastAPI + SQLite (SQLAlchemy), фронтенд — чистый JS без сборки, realtime — WebSocket, звонки — WebRTC.

## Запуск

```bash
cd dating_app
python -m venv venv && source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python -m app.cli download-models                    # нейросети для проверки лица (~38 МБ)
cp .env.example .env                                 # для локального запуска можно не делать
python run.py                                        # → http://localhost:8000
```

Без `.env` приложение работает в режиме разработки: письма с кодами печатаются в консоль,
а код подтверждения показывается прямо на экране.

Полезные команды:

```bash
python -m app.cli make-admin you@mail.ru             # выдать права админа (или ADMIN_EMAILS в .env)
python -m app.cli seed --lat 55.75 --lon 37.62       # 12 демо-анкет рядом с точкой (пароль Demo12345)
FACE_MODE=dev python run.py                          # отключить сверку лица (для тестов без камеры)
pip install -r requirements-dev.txt && pytest        # тесты
```

> Камера, микрофон и геопозиция в браузере работают только на `localhost` или по **HTTPS**.

## Что умеет

| Раздел | Как устроено |
|---|---|
| Регистрация по почте | Пароль: от 8 символов, заглавная буква, цифра. На почту приходит 6-значный код (15 минут, 5 попыток, повторная отправка через 60 с). Есть сброс пароля. |
| Вход через Telegram | Telegram Login Widget, подпись проверяется на сервере. Почта и пароль не нужны, но фото всё равно проходит проверку. |
| Проверка фото на фейк | После загрузки фото открывается сканер лица: «смотрите прямо → поверните влево → вправо». Сервер (OpenCV YuNet + SFace) сверяет каждый кадр с фото и проверяет, что голова поворачивалась, поэтому чужое фото, поднесённое к камере, проверку не пройдёт. Пока фото не подтверждено, анкету никто не видит. Новое фото — новая проверка. |
| Профиль | Имя, возраст (18+), описание, фото. Показ в любой из трёх лент или во всех сразу. Переключатель «Одно описание для всех лент»: если его выключить, у каждой ленты своё описание. Всё меняется в «Профиле». |
| Ленты | Анкеты отсортированы от ближайших к дальним (геопозиция браузера, радиус настраивается). Свайп вправо — нравится, влево — нет; работают также кнопки и стрелки на клавиатуре. Метч считается отдельно в каждой ленте. |
| Метч | Окно «Взаимно!», уведомление в реальном времени, письмо на почту, после этого открывается чат. |
| Мессенджер | Текст, фото, видео, голосовые, кружочки (до 60 с), стикеры, «печатает…», прочитано ✓✓, аудио- и видеозвонки, удаление пары. Медиа доступны только участникам чата. |
| Админка `/admin` | Статистика, поиск по анкетам, карточка пользователя: когда и откуда зарегистрировался (IP, координаты на карте, устройство), фото анкеты рядом с кадром сканера, история входов. Блокировка, сброс проверки, удаление анкеты, чтение переписок, e-mail рассылка об обновлениях. |

## Структура

```
dating_app/
├── app/
│   ├── main.py            FastAPI, раздача файлов с проверкой доступа
│   ├── models.py          таблицы БД
│   ├── face_verify.py     сверка лица и проверка «живости»

│   ├── realtime.py        WebSocket-соединения
│   ├── cli.py             make-admin, seed, download-models
│   └── routers/           auth, profile, feed, chat (+ сигналинг звонков), admin
├── static/                index.html, admin.html, css/, js/
└── tests/
```

## Перед продакшеном

- Задайте `SECRET_KEY`, `DEV_MODE=0`, `COOKIE_SECURE=1`, настройте SMTP и HTTPS (nginx + certbot).
- Для звонков через мобильные сети поднимите TURN-сервер (coturn) и пропишите его в `ICE_SERVERS`.
- Админ видит переписки, а лента 18+ — контент для взрослых. Пропишите это в пользовательском соглашении и политике конфиденциальности (152-ФЗ / GDPR) и указывайте возрастную маркировку 18+.
- При большой нагрузке SQLite стоит заменить на PostgreSQL (`DATABASE_URL`), а файлы перенести в S3.
