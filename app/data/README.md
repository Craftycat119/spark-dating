# Справочник городов

`cities.json.gz` — города мира от 5000 жителей: `[название, страна, широта, долгота, население]`.

Источник: GeoNames (https://www.geonames.org), лицензия Creative Commons Attribution 4.0.
Русские названия: Россия и СНГ — из альтернативных названий GeoNames, Вьетнам и популярные города — проверенный словарь
(`tools/build_cities.py`). Используется для подписи города в анкете по геопозиции, без внешних запросов.
