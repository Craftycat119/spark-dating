# Демо COFI одной страницей

Собирает всё приложение в один HTML-файл без сервера: сервер заменён имитатором в браузере
(`mock-api.js`), данные ботов и вопросы опроса берутся из `app/demo.py` и `app/interests.py`.

```bash
cd tools/standalone-demo
npm i esbuild@0.24.0
node build.mjs cofi-demo.html
```

Что работает так же, как в приложении: вход в демо и регистрация (код 246810), опрос,
лента с 10 ботами, подробные анкеты, пары, чат с ответами ботов, фото и видео в чате, стикеры,
профиль, галерея, тема, инструкция. Голосовые, кружочки, звонки и сканер лица требуют камеру и
микрофон, которых нет на странице по ссылке: на эти кнопки демо показывает пояснение.
Фото ботов рисуются на canvas, потому что внешние картинки на такой странице не загружаются.
